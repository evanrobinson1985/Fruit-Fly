Fruit Fly for Windows
=====================

1. Unzip this folder anywhere (for example your Downloads).
2. Double-click Install.cmd.
   It copies the game to your user folder (%LOCALAPPDATA%\FruitFly), puts a
   "Fruit Fly" icon on your desktop and starts the game.
3. Next time, double-click the Fruit Fly icon on your desktop.

The game opens in its own window (Microsoft Edge in app mode, or your default
browser if Edge isn't installed). Closing the window stops it. Everything runs on
your computer, offline: the 3D fly, its 165,122-neuron brain, the frogs, the
pond. It renders at high quality on a computer; add ?quality=low to the address
for a lighter version, or open http://localhost:47812/index.html?game for the
pet game.

Updates: each time you start it, it checks for a newer version and, if there is
one, downloads and installs it first (a small "Updating" window shows). Offline,
it just starts the version you have.

If Windows SmartScreen warns about Install.cmd, choose "More info" then "Run
anyway" (the file isn't signed). To uninstall, delete the desktop icon and the
folder %LOCALAPPDATA%\FruitFly.
